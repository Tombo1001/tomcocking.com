# tomcocking.com

Personal portfolio site for Tom Cocking — Security Consultant & IT Systems Engineer.

Hosted on [GitHub Pages](https://pages.github.com/) at [tomcocking.com](https://tomcocking.com).

## Structure

```
/
├── index.html          # Homepage
├── generic.html        # Generic page template
├── elements.html       # Style reference
├── assets/             # CSS, JS, SASS
├── images/             # Site images and favicon
└── CNAME               # Custom domain config for GitHub Pages
```

## Deployment

Pushes to `main` are automatically deployed via GitHub Pages. No build step required.
